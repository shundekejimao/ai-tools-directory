# Remio

本地优先的 AI 记忆和个人知识库桌面应用，能解析文件、网页、录音、邮件、消息、图片和笔记，并建立本地索引与向量，帮助用户和 Agent 快速检索需要的个人上下文。

## 功能特点

- 本地优先 AI 记忆和个人知识库
- 支持文件、网页、录音、邮件、消息、图片和笔记等多格式解析
- 通过本地索引和向量检索减少反复扫描文件、整篇读文档带来的 token 和成本浪费

## 不足之处

> CLI / Agent 工作流需要配合 Remio 桌面客户端使用。

## 推荐搭配

> 适合作为 NotebookLM、Mem、Obsidian AI、Agent 上下文检索工作流的本地个人知识层。
