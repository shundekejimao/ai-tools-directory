# Roblox GUI Maker

面向 Roblox 创作者的免费 AI GUI 规划工具，可根据提示词生成 ScreenGui、HUD、菜单、商店、背包和管理面板等界面方案，并提供 JSON 风格蓝图与 Lua UI 起步代码建议。

## 功能特点

- 根据文字提示生成 Roblox Studio ScreenGui 布局思路
- 适合规划 HUD、主菜单、商店、背包、设置和管理面板
- 输出 JSON 风格结构，方便整理界面层级与组件
- 提供 Lua UI 起步代码建议，帮助从想法过渡到 Roblox Studio 实现

## 不足之处

- 仍需要在 Roblox Studio 中手动搭建、调试和美化
- 更适合 GUI 方案规划与起步代码，不是完整游戏系统生成器

## 推荐搭配

- Roblox Studio
- Lua
- Cursor 或 GitHub Copilot
